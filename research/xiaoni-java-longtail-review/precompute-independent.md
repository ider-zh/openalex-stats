## 结论与调用边界

1. **存在明确的国家总量和国家×学科最小量筛选变体**，能在建 M 前排除长尾国家／边。但这些 `test` 方法在当前两个 `main` 均为注释状态，没有旧运行参数或输出清单证明历史采用。
2. `EconomicsFzx.main` 当前有效调用的是 90 行 `getMcpMap_year`、93 行反射迭代、94 行排名、103 行标准化。其普通建网方法没有国家总量门槛，支持学科集合筛选，使用已有比例文件；不能把 `test` 中的 zck／ck 自动归入普通算法。
3. 存在绝对量建边、世界学科均量建边、删稀缺学科、只保留多主体学科等多种路线；**这些定义互不相同，也不是全部已经启用**。
4. “最大连通子图”和“过滤低出口量后重算”的两个老方法只有空 `try`，不是已实现的稳健性措施。
5. 当前普通国家排名入口以 **US 单个参照国家**决定所有国家取哪轮迭代；这确实会影响结果，但不是针对长尾国家的显式收缩或筛除。

`FzxByCtry.main` 当前只有 60 行 `getMcp_end_filter_year_jg_union_EU` 与 80 行双网络非对称迭代生效；本文讨论的常规建 M 变体（65–72）与普通排名（99–102）均注释。它是更晚的国家／学校／联盟多实体研究集合，不能把每个 `ctry` 局部变量都解释为国家代码。

## 一、总量＋单格门槛：真实存在，但未在当前入口启用

### EconomicsFzx.getMcpMap_year_test（2887–3143）

- 2904–2907 从终端读取 `zck`（国家总出口阈值）和 `ck`（单学科出口阈值）；没有写死实际数值。
- 2983–2990 对中间表数组串的条目数累计 `map_country_total`。没有在本方法重新解析／去重引用标识；单位及去重性依赖上游中间表，不能直接声称是当前体系的去重论文数。
- 3013 的 `if (c_t < zck)` 分支所有插入代码已注释，实际整国不入 `map_country`；**等于 zck 仍可通过**。
- 3039 只有 `cc >= ck` 的单格进入国家比例表，仍用**删边前**的 `c_t` 求 `cc/c_t`。
- 3036–3037 额外硬排 `Korean culture` 学科。
- 3073–3077 世界比例读早先原文件，仅 `国家比例 >= global_cat && global_cat > 0` 形成 M。**本方法没有在删国／删边之后重算世界比例或国家总量**。2977 注释也明确留下“过滤掉的不应该算作总出口”的疑问。
- 当前 `main` 87 行该方法调用已注释；90 行调用的是另一普通方法。

因此，如果采用此变体，某极小国家即使单一学科 RCA 很高，也可能在 `c_t < zck` 处完全消失；一个够大的国家的少量专门学科，也可能被 `cc < ck` 删边。这是计算网络变化，区别于只隐藏输出。其分母是否应随筛选重算是独立方法选择，不能自动照搬。

## 二、普通当前建网没有隐含的国家规模门槛

`EconomicsFzx.getMcpMap_year`（3259）：3272–3275 的 `isFilter` 与 `yz` 控制中间文件／学科名单选择；3315 名单路径为 `filter_2020_{yz}.0.txt`，固定参考年，不随循环年度变化。3348–3355 只保留名单学科，3385 直接比较已有国家比例与已有世界比例。

本方法没有读取 zck／ck，没有固定国家白名单，也没有对国家论文总数、引用总数作阈值筛选；无边国家随建网消失是自然结果，不等同国家规模门槛。比例是在本方法外生成，不能仅靠读取文件名断言上游没有任何过滤。

当前普通反射方法读生成的 M，从边构建国家、学科邻接集合，再用度数初始化；没有发现按国家身份另加初值、先验概率或平滑常数来抑制长尾的证据。
