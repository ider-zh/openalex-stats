# 文献范围与引用统计口径

更新日期：2026-11-12。统计年份从2000起；类型采用黑名单；引用在圈定文献范围内重算。本版替代旧的主候选/扩展集合分流建议，尚未执行正式全库筛选。

## 已确认黑名单：15类

| 类型 | 排除原因 |
|---|---|
| editorial | 社论、编者按等非研究正文 |
| erratum | 更正通知 |
| retraction | 撤稿通知本身 |
| paratext | 封面、目录、编委名单等 |
| peer-review | 审稿意见，区别于综述review |
| reference-entry | 词典、百科等条目 |
| libguides | 图书馆导航资源 |
| supplementary-materials | 补充材料，避免作为独立论文重复计数 |
| book | 整本书不作为论文计数；书章仍保留 |
| dissertation | 学位论文不进入论文统计集合 |
| dataset | 数据集对象，区别于数据论文 |
| database | 数据库对象，区别于描述数据库的论文 |
| software | 软件对象，区别于软件论文 |
| grant | 资助项目记录 |
| standard | 技术标准 |

用户认可推荐方案后，采用基础13类加book、dissertation，共15类。未命中黑名单的类型默认保留，不另设隐含白名单。规则已记录，尚未执行正式全库过滤。

当前24种实际类型中，其余9种为article、review、letter、book-chapter、book-section、preprint、report、report-component、other，默认保留并记录类型。

仅凭type无法剔除article内部误标的书评、会议摘要；这些先标记，后续若需要应增加可审计的明确规则。标题、来源、raw_type等风险信号不自动变成隐藏排除条件。新出现或缺失的类型默认保留并标记。

is_paratext=true作为附属内容排除，本次审计中该标记与type=paratext一致。is_retracted=true的原研究文献与type=retraction通知不同，暂保留并标记；若要排除原文另设规则。

## 引用：双端都在统一集合内

令Q为最终圈定文献集合。A引用B，只有A和B都在Q中才计数：

- 引用发生年：A的发表年。
- 国家、学科归属：B的国家和学科权重。
- 施引A可以来自Q中任意国家和学科；图表选择不会改变Q。
- 每个(source_work_id,target_work_id)只计一次。
- 由referenced_works连接Q重建，counts_by_year只作对照，不用于限定范围的正式统计。
- 自引暂保留；无法连接的参考文献单独报告，不自动当作属于Q。

## 年份与未定边界

输出年份从2000起；完整日历年到2025，2026截至6月26日单列为不完整年。

是否将2000年前论文保留为被引对象，已向用户提问，尚待确认。2005年论文引用1995年论文：仅限制输出年时可计入；Q本身限制发表年>=2000时不计入。不能混淆这两个条件。

2000—2011需要由引用关系重建；因采用双端范围约束，2012之后也要重建。结果反映本快照可解析的引用图，不保证完整历史覆盖，缺失不能直接当作零。
