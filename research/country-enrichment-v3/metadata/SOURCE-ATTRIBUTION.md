# External source attribution

Crossref source: Dominika Tkaczyk / Crossref, [Crossref relationships involving research organisations, v2](https://zenodo.org/records/18500703), published 2026-02-06, dataset DOI [10.13003/ich4dosh](https://doi.org/10.13003/ich4dosh). Its 140,906,929 assertions contain data deposited through March 2025. This project uses individual author contributor-affiliation strings and original-author identity checks; it does not use machine-discovered ROR assignments as automatic country labels. Licensing and citation details belong to the linked source record.

PubMed source: U.S. National Library of Medicine / NCBI, [PubMed baseline bulk XML](https://ftp.ncbi.nlm.nih.gov/pubmed/baseline/), frozen January 2026 baseline, 1,334 files. Later daily updates are not applied. Country proposals derive only from the article's author affiliations after bibliography and author identity checks. The original XML remains in the private research evidence cache; public review derivatives omit email addresses and unrelated abstract text.

The external country overlay is a derived research artifact with frozen rules, source checksums and independently reviewed validation gates. It preserves the original OpenAlex country version for comparison.
