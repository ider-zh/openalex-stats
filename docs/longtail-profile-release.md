# 小倪补丁：计算前筛选与复杂度重算

网站在原国家补全版／原始版、Core／含 XPAC 全数据、小倪方法论／谱方法之外，增加独立的**复杂度样本筛选**。默认采用 `p1000-c1000-x5-d3-v1`，可一键切回 `baseline-v1` 原模型，或在折叠参数区动态选择 18 组已重算方案。

这采用旧 Java 国家规模／单格支持／优势学科数的筛选思路，修复其旧分母、末端跳过重编号和部分过滤未进入矩阵的问题。没有采用固定国家名单、参考国排名或按期望排名选参数。旧 Java 证据见[源码专项](xiaoni-java-longtail-review.md)，交互与单位见[操作说明](longtail-filter-controls.md)。

## 默认与可调门槛

| 门槛 | 默认 | 可选 |
|---|---:|---|
| 国家当年论文全计数 | ≥1,000 | 100／1,000／5,000 |
| 国家×学科原始赋值 X | ≥5 | 0（不设）／5／20 |
| 优势学科数 kc0 | ≥3 | 1／3 |
| 引用输入额外的国家当年引用事件 | ≥1,000 | 非 baseline 固定；不应用于论文输入 |

国家论文量逐 Work 在该国去重，从主 Topics Field 含 UNKNOWN 学科的全计数总量取得，不累加多标签 Concepts。单格 X 是国家均分、Concepts 命中全计后的赋值，可以为小数；引用赋值是事件数，不是独立被引目标论文数。推荐值是公开的工程研究起点，不是已验证的通用科研能力标准。

每个国家版本／语料／年度／层级／输入独立处理：

1. 不满足国家规模门槛的行置零。
2. 原 X 中低于单格门槛的值置零。
3. 从保留 X 重新计算行、列、总边际及 RCA，再形成 M。
4. 同步永久删除优势学科数不足的正量国家，重算 RCA／M，直到没有新增删除。
5. 谱方法与小倪 16／17 轮方法在同一个最终 M 上求 ECI／PCI。移除国家的合作份额不重新分配。

国家仍保留在选择器和下载词典中；被筛年度点无分值、无名次，并显示具体原因，不填 0 或最后一名。全球竞争排名来自完整有效模型，不随选中的国家／曲线重排。断连或退化继续显示不可比较状态。

筛选只改变 ECI／PCI 的模型输入及其内部 RCA；论文量、当年被引、份额、普通 RCA 曲线仍是基础统计，接口回显 `profile_applies=false`。两类 RCA 不混用。

## 方向可比性

最初独立重算发现，弱初年方向锚点可能让筛选模型整条轴镜像。首发使用明确的 `baseline-pooled-common-year-sign-v1`：先沿原规则逐年对齐，再按对应未筛选模型在 2000—2025 完整年、逐年共同国家上的中心化协方差累计，只选择一个全链符号，联合用于所有 27 年的 ECI／PCI。年份和国家 ID 固定排序、补偿求和；2026 不参与选符号，但应用同一因子。

不逐年翻号、不按指定国家挑方向。相关绝对值低于 0.2 标为弱参考，没有有效参考则保留原符号并标 unavailable；全部因子、相关和共同样本数可下载 `profile-direction.json`。Baseline 的发布分数、方向和名次逐位保持原样。该步骤使同一研究版本的参数对照具有一致方向，不把模型校准为国家科研实力。

## 实际效果与边界

2025、国家补全版 Core、小倪方法论：

| 口径 | 对象 | 未筛选 | 默认筛选 |
|---|---|---:|---|
| Topics Field／论文 | 朝鲜 KP | 2／229 | 年论文支撑不足，退出 |
| Topics Field／论文 | 新加坡 SG | 1／229 | 保留，1／147 |
| Topics Field／论文 | 中国 CN | 4／229 | 保留，2／147 |
| Concepts 0／当年被引 | 安提瓜 AG | 2／234 | 优势学科数不足，退出 |
| Concepts 0／当年被引 | 西撒哈拉 EH | 3／234 | 论文／引用支撑不足，退出 |

上述 Field 论文模型保留原已知且已归类 X 赋值的 **99.8203%**，有效国家／地区 147；Concepts 0 引用模型保留 **99.8943%**，有效国家／地区 146。这是赋值保留率，不是全球去重论文保留率。

仍有解释限制：Concepts 0 引用模型的新加坡和中国保留但仍在当前轴后端；这不能解释为能力下降，也不能宣称只要剔除长尾，所有排名就都变成科研实力顺序。国家误配、粗分类结构轴和有限反射敏感性仍见[既有审查](small-country-complexity-review.md)。补丁解决的是明确门槛下的低支撑排名，不为所有原国家标签或指标外部有效性背书。

## 计算、来源与接口

Go 使用四进程、每进程 12 workers，并行生成原始／补全 × Core／All 的完整结果；每组 19 profiles ×216 年度网络，总计 16,416 网络任务、32,832 方法结果。未重新统计无关数量。四组来自相同已审计基础 run／completion，profile run ID 另绑定源统计、字典、基线方法、参数、引擎二进制及方向政策。

公开参数为 `complexity_profile`。元数据给全部规则与默认；JSON 回显 profile、实际 profile run ID、年度入模国家／学科数、赋值保留率、闭包轮数及源 X／最终 X／M SHA。CSV、当前模型 JSON、分值 Parquet、配置、诊断和方向文件均绑定 profile 与方法。筛选版模型 JSON 省略巨大 RCA／M 数组，保留分值和来源，可由基础统计重建完整网络；不下载原敏感性报告冒充新模型。

所有参数组合离线由 Go 完整重算；浏览器动态切换预计算结果。Cloudflare 不依赖 229 API，也不在请求中重建模型。原计数／原模型分片逐字节保留，新增模型、下载与摘要按 profile run ID 隔离缓存。页面资源 URL 采用内容 hash，避免旧 JS 读取新默认数据时缺少筛选控件。

## 复核

- 四组全部 Artifact／源 SHA、baseline 浮点逐位、JSON／DuckDB 竞争排名及 Parquet 身份校验通过；筛选矩阵和诊断相对对齐前版本不变。
- 独立 NumPy 在 128 个原统计矩阵上复算 **2,432 个固定点**与最终 X／M SHA；检查全部 **32,832** 个模型排名和总体 z 标准化。
- 对三组预先选定参数，独立求解 **768 对**谱／16–17 轮分值；最大谱误差约 **5.91×10⁻¹⁴**，反射误差 **1.05×10⁻⁷**，均低于 10⁻⁶。
- 复核 **1,152 条**跨 profile 方向链，并逐模型证明全部 **32,832** 对输出只应用一个共同符号，未修改 X／M 或按国家改变分数。

源抽取与独立计算用不同实现，检查器见 [independent_check.py](../research/longtail-patch-v1/independent_check.py)，[NumPy 报告](../research/longtail-patch-v1/independent-v2/numpy-audit.json)绑定实际代码 SHA。

最终 Go 服务为 <http://192.168.1.229:8899>，默认国家补全版、小倪方法论、推荐筛选。原始国家版本、两语料、两方法与未筛选模型均保留。切换后额外完成 4 组 metadata、80 条代表性 series 和 5 件前端源码资源 SHA 对照；同名 Subfield 的 metadata 按稳定 ID 比较，全部标签与关系保留。

Cloudflare Node 兼容预览与官方本地 workerd **各自**通过 3,016 JSON／1,255,176 点、152 CSV、888 下载 HEAD、40 件下载实际字节及 SHA、8 类无效输入和默认值核对；另验证 432 个基础指标不变案例、608 个两方法支撑集一致案例。官方运行时 12 路冷并发通过。验收期间修正了全局共享未完成 I/O Promise 的请求上下文问题，以及静态 HEAD 空体长度问题；GET 可合法使用 chunked，不能把缺少 Content-Length 误判为空文件，验收始终检查实际完整字节数与 SHA。

官方 workerd 与正式 Go 网站各通过 11 组真实浏览器交互验收，桌面／手机均使用实际服务资源，无覆盖文件。构建为 16,349 文件、870,119,276 字节，最大 4,105,647 字节；其中 16,083 件数据逐 SHA 复核，14,264 件旧科学／下载 Artifact 逐字节保留。网站数据可独立部署至 Cloudflare，不依赖 229 API。公网账户部署仍由仓库所有者执行。
