# 国家补全 v2：分层抽样试验 Review

日期：2026-11-12。三组 subagent 已在 229 并行完成共同样本、Crossref／PubMed dump 和开放全文试验。原始 snapshot、原国家、原统计、引用图、ECI 和网站未替换。以下为待用户 review 的旁路结果；独立 agent 的来源核验不等于用户已批准入库。

## 执行范围与可复现性

共同抽样框是原国家为空的全部合格 Q：277,418,468 篇，其中 Core 150,377,414、XPAC 独有 127,041,054。按 Core／XPAC、年代和五类文献分 53 层，固定 hash 各层最多 128 篇，共 6,559 篇；没有 DOI、PMID 或原始署名文本的记录也保留在分母。保留 2000 年以前的合格被引目标，发表量输出从 2000 年开始，2026 为部分年。

样本 SHA256：`e3a93107f18985c07c217ceeb866fe072af674621b710ba74b3772599248630d`。Root 独立重算全部样本 hash、N/n、53 层人数与 Core／XPAC 分组，均通过；没有第二次扫描 4.04 亿条 Q 来独立证明 bottom-hash 最小性。详细设计和预先修订的网络范围见[试验协议](country-enrichment-pilot-v2.md)。

主体使用 Go 做抽样、稀疏读取、并发处理、元数据与 XML 解析、身份检查、加权统计；PDF 使用成熟 GROBID，Windows Node 仅作公开文件的网络运输。没有调用 Crossref REST、PubMed E-utilities 或逐 DOI／PMID 元数据 API；GROBID consolidation 全部关闭。

PubMed A／B 重叠文件只下载一次，最终 **205 个 gzip XML，7,041,241,402 字节，6,124,989 条 PubmedArticle**；逐文件官方 MD5 和收件／解析 SHA 一致。范围是 **2026 年 1 月 baseline 子集**，没有处理 daily updates，不是截至今天完整 PubMed。196 个原 PMID 中 1 个未解决，不能断言其不存在于全库。A 分片顺带命中的另一篇 DOI-only 记录属于错论文，已排除，不充当 A 路线收益。

Crossref 是署名专用 dump，不是完整且最新的 Crossref works dump；其中机构／集体作者字段不等于个人作者 affiliation。联合国、期刊所属大学或出版机构总部国不能直接充当论文作者国家。

PDF transport 的 337 个分母保持不变：105 个实际 PDF、96 个 HTML 等非 PDF、91 个 HTTP 错误、45 个运输错误。不能只用下载成功的 105 个当覆盖率分母。仅 31.16% 选中链接取得 PDF，按当前自动身份策略最终国家候选为 7/337；这不是人工审阅全部文件后的理论恢复率。

## 覆盖率与去重

加权结果使用共同抽样概率；PDF 另使用冻结的二阶段 π2。各路线先按 Work 去重，再扣除历史 v1／v1b 候选。只有明确完成的失败才是本次策略的恢复 0，未抽 PDF 和未扫描 PubMed 文件不能当作源信息不存在。

最终核验准入层使用 XML v2 与 PDF identity v3。只准入原预测已有、且独立来源核验通过的国家；不把核验发现的漏检国家填进旧预测。Go 合并程序与 Root 独立 Python 点估计及两阶段方差计算，以下数字逐值一致。

**这是探索性试验外推，尚无独立 holdout 验证。** 翻译题名、UK 别名和 PDF v3 身份规则是在本 pilot 的失败诊断后调整的；保留了旧版，但最终版收益与来源一致性仍在同一试验样本上评价。下列 SE 是按固定最终判定计算的设计误差，不包含规则调优及审查选择带来的乐观偏差。小总体穷举验证的是固定策略下估计公式，不是最终规则的样本外质量。

| 发表年窗口 | 版本／总论文分母 | 扣除 v1／v1b 后额外可补论文估计 | 标准误（1 SE） | 额外覆盖率百分点 | 百分点标准误 |
|---|---|---:|---:|---:|---:|
| 2000—2025 | 主数据 Core／191,419,523 | 1,116,640 | 505,845 | +0.583 | 0.264 |
| 2000—2025 | 含 XPAC 全数据／275,493,280 | 1,116,640 | 505,845 | +0.405 | 0.184 |
| 2000—2026 部分年 | 主数据 Core／201,267,475 | 1,155,161 | 507,310 | +0.574 | 0.252 |
| 2000—2026 部分年 | 含 XPAC 全数据／285,365,821 | 1,155,161 | 507,310 | +0.405 | 0.178 |

以上是**扣除旧候选后的额外收益**，不是在原覆盖率上直接加全部历史与本轮候选。对原始 baseline 的本轮联合点估计为 2000—2025 年 1,431,340 篇、2000—2026 年 1,469,861 篇；二者分别有 314,701 篇加权估计与旧候选重叠。Core／all 点估计相同是因为本次核验通过的新增样本都在 Core，不是已经证明 XPAC 永远无法补全。

2000—2025 年净新增观测只有 **12 篇**（一阶段已有来源 8、PDF 独有 4），含 2026 为 13 篇。少数案例经较大设计权重外推，因此误差较大，不能按百万级点估计承诺确定收益。标准误不是 95% 区间；稀疏成功层及重尾事件也使正态区间仅有近似解释。

引文按原圈定引用边、施引论文年份 2000 年起计算，保留更早发表的被引目标。Core 2000—2025 年扣旧后，可使原来目标国家缺失的引用事件估计增加 **21,574,533，SE 21,095,652**；含 2026 为 **21,869,146，SE 21,291,179**。这是可获得目标国家的原始引用事件估计，尚未分配到具体国家、学科或重算 ECI；重尾误差接近点估计，不据此给出精确引文覆盖收益承诺。

完整路线、窗口、逐年引文、方差分解和版本结果见[最终机器结果](../research/country-enrichment-pilot-v2/sample/merged-route-estimates-xml-v2-reviewed.json)及[Root 独立交叉计算](../research/country-enrichment-pilot-v2/review/root-point-check.json)。估计误差只反映抽样设计，不包含来源自身错误、规则变化、来源更新或未审案例的不确定性；不能解释为已经在全量数据上实现的新增。

## 准确率、错配与国家完整性

Root 核验了 60 条路线记录、48 篇去重 Work；其中 39 篇至少有一个来源的身份和预测国家获支持。这个 39 是已观测案例数，不是全国／全量净新增，也不能直接加总成加权总收益。逐条清单、证据 SHA 和核验理由在[review 索引](../research/country-enrichment-pilot-v2/review/review-index.md)与[结构化判定](../research/country-enrichment-pilot-v2/sample/review-overrides.json)。

PubMed A 28/28、XML 7/7、PDF 7/7 指的是**本次候选逐条核验后的来源一致性**。样本小且不是独立人类金标准；没有核验全部阴性，所以不报全量准确率 100%、召回率或 precision-adjusted 全量预测。PubMed 比较了本文 Author/AffiliationInfo，排除了期刊出版国；旧记录可能只提供首作者单位，不能据此证明所有合作者国家已恢复。XML 检查 contrib/xref/aff；PDF 对照原文件渲染首页，带封面的预印本还检查正文第二页。

若将 Crossref 的 17 条直接国家候选不经身份门槛就入库，本批至少 2/17（11.8%）会补到错论文；9 条确认、6 条仍不确定。这个比例仅描述本批，不能外推为整个 Crossref 的错误率。PDF 7/7 的已提取国家有依据，但对照本批原文可见署名，只有 6/7 未发现国家集合遗漏；“已有国家正确”不能替代“国家集合完整”。

需要 review 的显著案例：

- **W19239315**：原文是 2003 年日本地方文章，DOI 却指向 2009 年化学论文，题名、作者、年代均冲突；真实化学论文 PMID 恰为 19239315。不能把其美国署名国家回填到原 Work。
- **W26184156**：原文是 2006 年摄像算法，DOI 指向 2015 年黑色素瘤论文，且真实 PMID 恰为 26184156。同样排除。
- **W34102155**：原文 CFD/PIV 2010，顺带 DOI 命中眼科论文 2021，作者亦不同；不补 CN。上述现象只证明冻结数据存在身份污染，未审转换链前不归责某一上游服务。
- **W7117252406**：PDF 提取到 BD 正确，但另一个 Jadavpur／Kolkata／West Bengal 作者单位还支持 IN，当前预测漏掉这一国。保持原预测供 review，没有把审查 gold 偷填回旧结果。故“有至少一国”覆盖率与“完整国家集合”是不同质量指标，后者直接影响跨国分数计数。
- **W4400909141**：原 Work 作者数组为空，身份由精确 DOI、长题名和年份支持；不能声称已经比对原作者。
- **W4388718030**：原 2023 记录取回 arXiv 2024 v2，ID、题名、作者一致；仍保留版本与历史署名是否变化的限制。

PMC v1→v2 新增 3 个案例分别来自翻译题名、明确 UK 别名与失败源下载重试；PDF 原生→统一网络运输由 3 个变 5 个，严格作者规则 v3 再变 7 个。保存全部版本，不把代码改进、下载重试和来源收益混成一个数字。

以上阶段并发或含重试，不能直接相加为整体 wall time；字节是应用正文量下界，不能当账单流量。Windows 桥接 CPU／RAM、完整 Maven 下载和人工 review 工时没有完整计量，因此不虚构货币成本或“每新增正确论文只需几毫秒”。未使用收费服务。PubMed baseline＋updates 的约 77.5 GB 完整镜像尚未执行。

小样本受外部来源速率和可用性限制，没有为追求 90% 占用而扩大请求压力或填满 RAM。Go 并发主要用于本地扫描、解析与稀疏读取；PDF 使用成熟工具比另写版面识别器更有效。

## 建议与保留版本

优先考虑 PubMed 明确作者 affiliation 与 PMC JATS，前提是身份检查通过；它们结构清楚、容易追溯。Crossref 必须补身份及角色门槛，不能 DOI 一连就入库。PDF 适合作为前两路之后的受控补充，先改进题名／发表版本处理、国家集合完整性与失效 OA URL，不建议直接无差别全量抓取。

本次 PubMed DOI-only 概率分片的有效样本很少，不能据此否定完整 dump 的潜力；若扩大，先提高 DOI-only 来源评估样本量，再决定完整 baseline／updates 投入。没有标识符或全文入口的记录仍是主要缺口，已执行路线不能保证把原约 49% 覆盖率推至某个预设目标。

全部旁路产物保留在 229 `/mnt/nvme0/public/openalex-stats/analysis-country-pilot-20261112/`，源码、报告与小型核验包镜像在本项目 `research/country-enrichment-pilot-v2/`。原始来源、失败、checkpoint、XML 两版与 PDF 三版均保留；未覆盖原国家。原 XML 私有原件、邮件和许可不一的全文缓存不公开推送。

Root 复核 metadata 的 21 个产物 SHA、全文 28 个 review packet 原文件／TEI SHA，全部一致。原 snapshot manifest SHA 仍为 `10c1785b4a6f9757823fc6dd005a052716e2c510ea751659cab4bcfba4c35e2a`。8899 原生产 PID／二进制 SHA 保持不变，首页 HTTP 200；本次试验 GROBID 已按 PID／exe／argv／startticks 精确关闭。

Go 检查通过：元数据 2 项语义测试、全文 5 组测试、合并 6 项测试（包括一／二阶段全部小总体抽样组合的均值与方差无偏验证）。Root 另核对 739 条 PDF hash、51 层 bottom-8、337 条 π2、29 份 PubMed 原 XML 派生件 SHA，以及 16 项 Go／Python 独立点估计与标准误，均一致。关键合并代码：[main.go](../research/country-enrichment-pilot-v2/sample/merge/main.go)、[两阶段估计](../research/country-enrichment-pilot-v2/sample/merge/twophase.go)、[穷举验证](../research/country-enrichment-pilot-v2/sample/merge/twophase_test.go)。
