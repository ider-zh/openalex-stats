# 国家补全 v2：分层抽样试验协议

日期：2026-11-12。状态：旁路试验已完成、独立 agent 来源核验与加权交叉计算通过，待用户 review，见[结果报告](country-enrichment-pilot-v2-review.md)。三组并行负责共同样本、Crossref／PubMed 元数据、开放全文署名。正式快照、原国家、引用图、统计结果和网页均不替换。

## 共同样本与估计对象

- 基线为原快照合格 Q 中国家集合为空的全部 **277,418,468** 篇：Core 150,377,414，XPAC 独有 127,041,054。
- 使用 Go 扫描完整维度窄列，以固定 hash 在 Core／XPAC、年代和五类文献类型形成的 **53 个非空层**内概率抽样，共 **6,559 篇**。每层总体 N、样本 n、抽样概率和 seed 由 sample manifest 冻结。
- 年代包含 2000 年以前的被引目标、2000—2009、2010—2019、2020—2025、2026 部分年；无效或超出范围年份另列。论文量输出仍从 2000 年开始，引用收益保留早期被引目标。
- 不使用仅保留已有署名文本的 unresolved 文件作为总体框，也不只选择有 DOI、PMID 或 OA 链接的记录。第二阶段补原字段后，标识符／全文可用性是试验结果之一。
- v1／v1b 原有候选按 Work ID 标记，分别报告对原基线的新增与扣除这些候选后的额外收益。未完成标签核对的记录不得默认为不重叠。

## 数据获取约束

元数据优先使用已存在或可取得的 dump，不调用 Crossref／PubMed 逐条检索 API。Crossref 优先评估官方署名专用 JSONL dump，而非无必要下载完整 works dump；PubMed 使用 baseline XML 和所需更新文件，并保留修订／删除的应用顺序。dump 尚未完整扫描或版本未覆盖的记录，不能直接记为“来源不存在”。

全文优先已有内容和结构化出版者／PMC XML；PDF 使用成熟 GROBID 组件，Go 负责调度、文件处理和统计。GROBID 的 header、reference、funder consolidation 全部显式关闭，防止内部触发 Crossref 等元数据 API。PMC 官方公开内容对象／批量 inventory 的读取是内容文件路线，不借其替代 PubMed 逐条元数据查询。

只获取试验需要的公开内容，匹配 DOI／PMID、题名、作者、年代和版本。当前外部元数据可能晚于原快照，记录其版本与获取时间；不悄悄改变原 Work 的年份、类型、Q 或引用边。

### PubMed 网络成本后的预先范围修订

在 PubMed 匹配结果产生前，基于约 77.5 GB baseline＋updates 和实际网络测速，将首轮改为成本有界的 dump 试验，而非数小时以上的完整镜像；仍不使用逐条元数据 API。

- A：对共同样本中 196 个带 PMID 的记录，利用实际核验的 baseline 分片边界索引定位所需文件；标注 2026 年初 baseline vintage。未能定位、超出版本、记录不存在和缺署名分别记录。不能凭文件名猜 PMID 范围。
- B：对 baseline 文件序号的四个等量区段固定 hash，各抽 8 片，共 32 片；源文件选择清单、seed 和概率在命中结果前冻结。A 与 B 重叠文件只下载一次，但两种抽样机制不能混为一谈。
- B 可对“实际扫描文件集合下的去重 Work 收益”按共同 Work 样本概率估计。若用源分片概率外推整个 PubMed，应处理同一 DOI 多 PMID 的重复；记录链接总量不是唯一 Work 覆盖率，不满足唯一性条件时只给适用范围或探索性区间。
- 本轮不声称已经完整评估 2026 年 11 月 PubMed 全集；更新文件的成本和未评范围单列。后续完整镜像属于可另行选择的投入。

## 署名与国家候选规则

- 国家证据必须来自本文作者的署名机构／地址，保存作者—单位对应和来源定位。
- PubMed `MedlineJournalInfo/Country` 是期刊出版国，不可用于论文国家；本文 DOI 不能从参考文献 DOI 中误取。
- 全文不得从参考文献、致谢、研究地点或出版者地址抽国家充当作者署名。
- 直接地址／结构化国家、出版者明确提交的机构 ID、机器机构匹配分别标注。机构名、城市、域名、分校和国家冲突单列，不把匹配得分等同于准确率。
- 不以作者姓名、语言、期刊国家、作者当前单位或国籍直接填补历史论文署名地。包含不确定国家的候选集合不得进入高置信净增益。

## 覆盖率与去重

各路线逐层报告：标识符可得、来源命中、文件可达、下载成功、解析成功、出现可支持的国家候选、冲突和未决。失败原因保留分母；未尝试和不在数据版本范围内不混作提取失败。

对于完成观察的一阶段样本，用每层 N/n 权重估计总体新增；SRS 不放回抽样方差为 `Σ N_h²(1−n_h/N_h)s_h²/n_h`。小样本、未完成观察或覆盖不足时，给适用范围及不确定性，不输出伪精确全库比例。

XML 对共同样本尝试。若 PDF 数量较大，按可用候选在各层固定 hash 作第二阶段子抽样，记录额外概率 π2；未抽 PDF 不是失败。PDF 收益使用两阶段权重，不能把可下载 PDF 内的成功率直接外推到全部缺国家文献。

元数据、XML 与 PDF 先按相同 Work ID 扣重。估计 PDF 的额外收益时，对已由元数据或 XML 识别的记录扣除，再按 π2 和一阶段概率加权。论文量覆盖窗口、全 Q 覆盖和被引事件国家覆盖分别统计；后者可使用抽中目标的原整数引用计数，不能用 Concepts 多标签赋值代替独立事件数。

## 准确性评估与 review

候选覆盖率与准确率分开。每路线从成功、失败及冲突结果中固定概率抽取审查队列，提供来源 ID／DOI、署名原文定位或首页、原始文件 SHA、作者关联、候选国家和规则。主观挑选的容易案例不用于总体准确率估计。

审查必须回到原 XML／PDF／出版署名，不能用同一份解析输出自证、用 OpenAlex 已知国家作真值，或把共享同一上游来源的一致当独立确认。分别记录 Work 匹配、作者关联、国家集合中错误国家以及国家集合不完整。

Agent 的逐条原始证据核验与用户人工 review 分开。报告核验数量、抽样方式、准确性估计／区间及未核实比例；无法独立核实的记录单列，不能剔除后宣称 100% 准确。所有试验候选在用户 review 前均不自动应用。

## 成本、资源与复现

分别记录下载、一次性组件构建／索引、dump 扫描、解析、国家匹配、扣重及核验的耗时、CPU、峰值 RAM、磁盘和网络字节。固定 setup 与可复用成本、边际处理成本分开；按成功新增和已核实新增两种口径给成本，不假设每篇都要重新下载整个 dump。

计算与调度优先 Go；使用 DuckDB、XML/PDF 专用组件等明确更适合的工具时记录理由。保留不少于 64 GiB available RAM，不改服务器全局配置，不停止其他任务。

服务端统一根目录为 `/mnt/nvme0/public/openalex-stats/analysis-country-pilot-20261112/`，按 `sample`、`metadata`、`fulltext` 分离。保存源版本、来源 URL、文件校验、随机 seed、N/n/π、程序身份、命令与检查点；原始署名去除邮箱，未审定原文不发布到公开仓库。
