# 当前计数口径：Concepts 命中计一篇

更新：2026-11-12。用户明确要求取消Concepts同层标签均分；本文件覆盖此前Goal/说明中“Concepts均分”的默认值。旧结果与旧版本验收记录继续作为历史产物保存。

- 在选定的Concepts层级内，先按Concept ID去重，重复标签使用最高有效score判断阈值。
- 通过阈值的每个不同标签，各计入1篇。score仅用于筛选，不用于比例分配。
- Level0与Level1分别统计，各层独立处理，不混合父子标签。
- 被引计数使用同样规则：该论文在某年收到m次范围内引用，则每个命中的学科各计m次。
- 国家全计数：每个署名国家、每个命中学科各计1篇；论文量与引用次数应为非负整数。
- 国家均分：若署名涉及n个去重国家，每个国家、每个命中学科各计1/n篇；跨国合作仍可能产生小数。
- Topics仍按primary_topic的Field/Subfield各归属一个标签。
- 没有可用学科标签的论文进入UNKNOWN，不从统一文献集合Q移除。

例如一篇中美合作论文命中生物学、化学两个Level0标签：国家全计数时，中国生物学1篇、中国化学1篇、美国生物学1篇、美国化学1篇；国家均分时上述四格各0.5篇。

不同学科存在交叉，不能把命中全计数的学科数直接相加当成全国独立论文总量。全国总量应按国家—年对Work ID去重；学科矩阵总量是论文—学科归属次数。

主阈值仍为score>=0.3，敏感性阈值0和0.5。默认六场景均采用Concepts命中全计数，场景ID明确包含concept-whole；主ECI/PCI使用国家均分×学科命中全计数，四层×发表量/当年被引共八套模型重新计算。

类型黑名单、core范围、保留2000年前被引目标、双端都在Q、引用按施引发表年、排除同Work自环、作者自引保留、2000—2025默认完整日历窗口及2026部分年均保持原统计定义。因此文献维度和整数引用图可复用，学科聚合、份额/RCA、ECI/PCI及下载文件必须生成新的不可变结果。

验证分别核对原始论文/引用事件、去重学科归属次数、国家×学科归属次数及全计数整数性。Concepts命中全计数下不再要求跨学科求和等于去重论文数；Topics及历史显式fractional场景仍按其对应守恒关系核对。
