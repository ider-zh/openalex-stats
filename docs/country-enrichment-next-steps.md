# 国家覆盖率：下一轮补全路线

2026-11-12。用户授权的 Crossref／PubMed dump 与开放全文分层抽样试验已完成，见[结果与 review 报告](country-enrichment-pilot-v2-review.md)和[试验协议](country-enrichment-pilot-v2.md)。以下保留路线选择依据；正式统计尚未采用试验候选。

## 为什么当前字段的增量有限

在 Core、2000—2026 输出窗口中，原缺国家文献为 103,275,459 篇，其中仅 9,714,113 篇有原始署名单位文本，约 90.6% 连这类文本都没有。已有机构代码／地址末尾明确国家的规则已完成全量评估；继续放宽名称相似度，无法为大部分空白记录创造新的署名证据。

分母、窗口和候选版本见本地保留的[上一轮完整报告](country-enrichment-review.md)与[primary summary](../research/country-enrichment-v1/evidence/country-enrichment-review-v1/primary/summary.json)；这两份待 review 证据未发布到公开仓库。不同规则的新增量需要按 Work ID 去重，不能将各路线的命中数直接相加。

## 建议优先级

| 优先级 | 路线 | 证据与实现边界 |
|---|---|---|
| 1 | 外部论文元数据补回 | 以 DOI／PMID／Work ID 精确连接 Crossref、PubMed、更新后的 OpenAlex 等记录，取得论文发表时的署名单位或地址；同时核对题名、年份、作者等，发现 ID 或版本冲突就单列 |
| 2 | 出版者 XML、开放全文 | 优先解析结构化作者—机构对应；没有 XML 时提取 PDF 首页署名。用成熟 GROBID 服务处理 PDF，Go 负责下载队列、缓存、并发、检查点和去重 |
| 3 | 多证据机构消歧 | 联合机构名称、上级机构、城市、行政区、邮编、域名与 ROR；保留海外分校、同名机构和历史名称的歧义，不以全球总部所在地替代实际署名地点 |
| 4 | 作者同期机构辅助 | 可靠作者 ID／ORCID 加发表年份附近的机构记录生成候选；当前任职地、作者国籍、姓名和语言不能直接替代历史论文署名地 |
| 5 | 多语言地址解析 | 对已有地址的剩余记录识别国家别名、城市、行政区和邮编组合；无唯一证据则不强填，解析或大模型输出必须保留支持文本 |

前两条可以为“本地没有署名文本”的记录提供新信息，因而是更大增量的主要候选来源；实际能够提升多少，仍须测量外部可连接率、外部字段存在率及正确率。Crossref 与 OpenAlex 可能共享上游来源，一致并不自动构成两份独立证据。

ROR 官方提供批量数据和可本地部署的匹配 API；可以避免对每条记录串行访问远程服务。成熟的机构匹配／PDF 解析服务作为明确更合适的组件调用，工程调度及统计继续使用 Go。

## 建议的第一步评估

1. 在剩余 UNKNOWN 中盘点 DOI、PMID／PMCID、OA 全文入口、作者 ID／ORCID、机构 ID、原始署名文本的可用性。尚未取得这些数量，不能承诺某一目标覆盖率。
2. 按 Core／XPAC、年代、文献类型、标识符和署名可用性分层抽样，先试验外部元数据及全文两条路线。年代分层至少区分 **2000 年以前的合格被引目标**、2000—2009、2010—2019、2020—2025 和 2026 部分年。论文量输出仍从 2000 年开始，引用补全不能因此丢弃更早目标；两种收益分母分别报告。
3. 记录每条路线的独立新增、与已有候选重叠、冲突、处理成本和来源版本；用分层权重估计全量增益。对照已有国家标签只是一致性检查，人工金标准应回到出版署名／原文。
4. 对高收益路线全量运行可恢复的旁路任务；每条 patch 记录原集合、候选集合、匹配层级、原文证据、外部标识符与日期。任何重算均另存版本。

## 同时补全与纠错

KP 审计已发现泛化自然科学机构名称被错误匹配到朝鲜机构的案例。它说明“某篇至少有一个国家标签”不等于该标签正确，也不等于国际合作国家已经完整。

下一轮应分别报告：

- 原 UNKNOWN 新增有依据的国家标签；
- 已知国家集合扩张，及其造成的国家均分权重变化；
- 原有错误国家标签修正或移除；
- 冲突／无法判明的记录与质量分层。

不能只以填满率选规则。补丁进入统计前，需要重新计算所有受影响国家的分摊权重、份额／RCA 和复杂度；不应只增加某个国家的分子。正式原版保留，弱推断候选与有直接署名依据的结果分开。

## 核实的原始来源

- [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/)：可获得成员提交的署名、ORCID、ROR 等字段，不保证所有论文都有这些信息。
- [PubMed Affiliation 字段](https://dtd.nlm.nih.gov/ncbi/pubmed/doc/out/240101/el-Affiliation.html)：论文发表时的作者单位；2014 年起可包含出版者提交的每位作者单位，早年覆盖不同。
- [PubMed 批量下载](https://pubmed.ncbi.nlm.nih.gov/download/)：年度 XML baseline 与更新。
- [GROBID 官方服务文档](https://grobid.readthedocs.io/en/latest/Grobid-service/)：PDF 文献头、全文及署名地址解析接口。
- [ROR 匹配指南](https://ror.readme.io/docs/matching)：名称、位置、域名、完整 affiliation、本地数据及本地 API 等路线；API 的 chosen 仍是匹配决策，需要本研究的冲突验证。
- [ORCID 任职数据](https://info.orcid.org/documentation/workflows/employment-workflow/)：机构及起止日期等信息，不能直接证明特定论文的全部署名地。
- [OpenAlex 原始署名与匹配](https://help.openalex.org/data/raw-affiliation-strings/)：原始字符串、机构匹配及国家推断的关系；当前文档晚于冻结快照，不替代具体历史记录证据。
