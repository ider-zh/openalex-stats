# 复杂度样本筛选：小倪补丁与未筛选对照

本功能将样本门槛用于**建模之前**：从当前国家版本的统计输入筛选，重算 RCA、优势网络与 ECI／PCI。它不采用旧 Java 的计算后跳过对象、再重编榜单的做法。原模型保留为 `baseline-v1`，分值与全球名次不因对照功能被改写。

## 独立选择与默认方案

- 国家信息版本仍为 `original`／`enriched`，默认国家补全版；语料仍为 Core／含 XPAC 全数据。
- 复杂度求解仍为小倪方法论／谱方法；两方法使用同一 profile 的筛后输入与网络，各自求解。
- 新增 `complexity_profile`。默认 `p1000-c1000-x5-d3-v1`，不筛选对照为 `baseline-v1`。
- 主按钮在筛选／不筛选之间切换，折叠面板提供三个有限参数；恢复推荐按钮回到默认组合。每次选择请求对应的独立预计算模型，不由前端裁曲线充当重算。

18 个筛选组合为以下三项的笛卡尔积；所有最小门槛均包含等于值：

| 参数 | 可选值 | 实际含义 |
|---|---|---|
| 国家年论文量至少 | 100／1,000／5,000 | 当前国家版中该国当年发表论文的全计数，每篇在该国去重；从 primary Topics Field 含 UNKNOWN 学科的总量取得，不对多标签 Concepts 求和 |
| 国家×学科单格赋值至少 | 不设（0）／5／20 | 原模型 X 的国家均分赋值；Concepts 同层命中标签全记。论文基础是论文赋值，被引基础是被引事件赋值，允许小数 |
| 优势学科数至少 | 1／3 | 重算优势网络中的行度 `kc0`，是优势学科个数，不是论文数或论文质量 |

非 baseline 方案在被引基础中还固定要求国家当年被引事件至少 **1,000** 次；这一项不应用于论文基础。它是引用事件量，**不等于不同被引目标论文数**。ID 为 `p{论文门槛}-c1000-x{单格门槛}-d{优势数}-v1`；baseline 全部门槛为 0。

国家规模门槛和单格赋值门槛不是同一单位。推荐值是本项目预声明的研究参数，不是学界认证的通用标准，也不保证指标已通过科研能力的外部效度验证。国家国土面积、人口、身份或是否符合预期排名不参与筛选。

## 计算与数量口径

筛选先剔除国家总量不足的行，再将支持不足的原单格置零；随后重算 RCA 与优势网络，逐轮剔除优势学科数不足的国家，重算到保留集合稳定。被移除国家的合作份额不分配给留下的国家。两方法在同一最终网络上计算，先沿各自既定年度定向规则输出分值，再按下面的基线方向约定比较。

筛选只应用于 ECI／PCI。论文量、当年被引、份额、普通 RCA 曲线仍读取当前国家版本的基础统计，`profile_applies=false`；这些曲线不因 profile 改变。**普通 RCA 曲线和复杂度内部重新计算的 RCA 不混用**，界面有相应说明。

不筛选版本精确沿用原模型，不把筛后样本补回后重新排序。不筛选时不显示虚构的“赋值保留率”，仅说明正在使用原模型。

### 对应基线的全链方向对齐

筛选方案与对应未筛选基线统一对齐方向后比较；方向对齐不改变筛选网络，也不将指标校准为国家科研实力。

每个国家版本／profile／求解方法／分类层级／计算基础先完成原年度 Align，再对 **2000—2025 完整年**逐年的共同国家分值计算中心化协方差并累加，选取一个符号因子。该因子同时作用于全 27 年（含部分年 2026）的 ECI 与 PCI。

这是整条年度链的一次符号约定，不逐年翻号，也不指定新加坡、中国或其他国家来调整排名。改变页面时间窗口、显示国家或学科选择，不会重选符号。单个年份仍可能出现实际结构差异，不能把所有排名变化都归为方向问题。

baseline 的已发布分数与名次完全不动；`model_context.direction_policy` 为 `published-baseline-v1`。筛选方案为 `baseline-pooled-common-year-sign-v1`。客户端与验收核对这一策略，防止以旧的未对齐候选模型配上“已对齐”说明。

## 界面状态与全球名次

样本筛选区域只在 ECI／PCI 下出现。切换方案保留选中国家、学科、时间、计算基础、方法和 Bump／分数视图。某国不满足门槛也不会从国家搜索或已选标签中消失。

- 被筛除的年度点 `value=null`、`rank=null`，显示“不满足样本门槛”及国家年论文量、被引事件、单格支持或优势学科数等具体原因。
- 图中保留缺口，不填 0 分、0 名或最后一名。一个年份被筛除不影响其它年份有效数据。
- Bump 名次来自该年完整筛后模型中的全部有效对象；国家选择只改变显示，不重算名次。筛前、筛后的入模总体可能不同，名次变化不能全解释为科研能力变化。
- 终年摘要从 `model_context.years` 读取完整模型的入模国家数、学科数与赋值保留率，不从已选曲线推算。赋值保留率是已知国家、已归类 X 的赋值总量比例，不是全球去重论文保留率。
- 断连／退化继续显示模型诊断，不伪装成样本门槛问题。场景或年份未提供模型时明确留空，不回退到另一个 profile。

请求中清空旧模型图、终年表与旧响应缓存，并暂时禁用下载；只有请求身份、profile、方法与模型上下文匹配后才提交结果。过时请求的成功或失败不会覆盖后来的选择。返回的筛除点如果含非空分数／名次，前端拒绝绘制。

## 数据契约与产物

catalog／meta 的 `complexity_profiles` 列出 19 个不可变方案，`default_complexity_profile` 指向默认值。条目包含 `country_min_publications`、`country_min_citation_events`、`cell_min_support`、`min_diversity`。URL 明确携带 `complexity_profile`，分享与刷新保留选定方案；没有声明该功能的旧服务只使用原模型，前端不向旧 API 发送新参数。

series 回显 `query.complexity_profile`、完整 `complexity_profile` 条目、`profile_applies`、`profile_run_id`，以及 `model_context.profile_id`／`profile_run_id`／`direction_policy`／源身份和按年诊断。ECI／PCI 即使当前场景无模型也回显方案身份；数量与普通 RCA 不应用筛选。

曲线 CSV 末列保留 profile ID、应用标志和 profile run ID。模型下载同时绑定国家版本、方法与 profile：

- `eci.json`、`country_eci.parquet`、`discipline_pci.parquet` 指向当前求解方法和样本方案的模型／分值；筛选版为轻量模型，不宣称包含完整原网络。
- `profile-manifest.json` 与 `profile-diagnostics.json` 提供当前筛选配置与诊断。非 baseline 使用“当前筛选模型诊断”链接，不下载旧 baseline 的 12／20 轮敏感性文件冒充新模型诊断。
- baseline 保留原 `method-sensitivity.json`。筛选版不显示不可用的旧 `method-completion`／`method-audit`／`method-sensitivity` 下载别名。
- 基础 statistics／cube／普通 RCA／run 产物仍是当前国家版本的未筛选数量统计，界面明确标记为基础统计。Cloudflare 共享这些分片，只增加有限模型与诊断。

可下载项以 `meta.profile_model_downloads` 为准，不由前端猜测服务器路径或生成不存在的参数组合。
